# De Grote Matchmaker

Een zelfstandige Nederlandstalige quizwebapp. Open `index.html` in een moderne browser om de app te starten. Er is geen installatie of server nodig. De kandidaatfoto’s staan naast de HTML-pagina.

De Google Fonts laden online wanneer er internet beschikbaar is; de app gebruikt automatisch systeemlettertypes als dat niet zo is.
